# BulkText Web 0.19.9 — Accessibility & Form Interaction Audit

Frontend release: `0.19.9`  
Backend contract: `0.18.5`

This release applies a narrow accessibility/form audit across auth, profile settings, phone-number checking, recipient import, message composition and the simple campaign flow.

It adds programmatic helper/error associations, async busy semantics, alert/status feedback, required/invalid state exposure and accessible result naming while preserving existing workflow, database, PWA, offline, gateway and performance behavior.

No database migration is included.

See `docs/ACCESSIBILITY_FORM_INTERACTION_0199.md` and `VALIDATION_0_19_9.md`.
