# Web 0.18.10-a1 — Phone & SIM Mobile Responsive Correction

BulkText Web `0.18.10-a1` is a narrow presentation-only correction on top of Web `0.18.10`. It fixes mobile width containment in the `Phone & SIM` workspace, including pairing QR/code content, device/SIM cards and the pairing-history table.

Frontend version is `0.18.10-a1`; backend contract remains `0.18.5`. There is no database migration, delivery-contract change, service-worker change or Android change.

The next reliability patch keeps its existing name and scope: **`0.18.10-r1 — Offline Draft & PWA Reliability`**.

See `PATCH_0_18_10_A1_README.md`, `VALIDATION_0_18_10_A1.md` and `HANDOFF_0_18_10_A1.md`. The base offline-draft release documentation remains in `PATCH_0_18_10_README.md`, `VALIDATION_0_18_10.md`, `HANDOFF_0_18_10.md` and `docs/OFFLINE_DRAFT_WORKSPACE_01810.md`.
