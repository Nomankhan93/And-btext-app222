# Web 0.18.7-r2 — Mobile Bottom Navigation Refinement

Mobile-first BulkText campaign workflow with persistent bottom navigation on mobile: Home, Campaigns, Phone & SIM and expandable Tools. Desktop keeps the existing sidebar. This refinement sits on the validated Web 0.18.7 Mobile UI/UX release and changes presentation/navigation only.

Frontend version is `0.18.7-r2`; backend contract remains `0.18.5`. No database migration is included. See `PATCH_0_18_7_R2_README.md`, `VALIDATION_0_18_7_R2.md` and `HANDOFF_0_18_7_R2.md`.

PWA installation, service worker and offline caching remain deferred to Web 0.18.8.
